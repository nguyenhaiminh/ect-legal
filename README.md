# ECT Legal

Ứng dụng web tĩnh hỏi–đáp pháp lý Việt Nam về hợp đồng điện tử và chữ ký số.

## Chạy cục bộ

Mở `dist/index.html` hoặc chạy một static server trong thư mục `dist`.

## Phạm vi

- Hợp đồng lao động điện tử
- Hợp đồng thương mại điện tử
- Giá trị pháp lý và lưu trữ thông điệp dữ liệu
- Chữ ký điện tử, chữ ký số và chứng cứ điện tử
- Checklist tự rà soát trước khi ký

Nội dung mang tính tham khảo, không thay thế tư vấn pháp lý cho vụ việc cụ thể.
